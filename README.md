# Local Commerce Marketplace

This repository contains the codebase structure for the Local Commerce Marketplace, structured as a TypeScript monorepo with workspace packages:

- `lib`: Shared domain types, interfaces, business rules, and state machines (`@local-commerce/lib`).
- `backend`: Backend API service, controllers, services, and DTOs per feature domain.
- `frontend`: Frontend UI components, pages, and service integrations.

## Building the Monorepo

```bash
npm run build
```
